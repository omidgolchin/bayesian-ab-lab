How the verdict is decided rules, formulas, sources

Ship the leading version only when all four hold: the traffic split matches the plan; the chance it is better clears your bar; the expected loss if it is not better is small next to the smallest lift worth acting on; and the classic evidence agrees (p below the significance level, using the always-valid p-value if you checked more than once). Requiring both reads to agree keeps the verdict from resting on one method's blind spot.

Stop: no meaningful difference when the 90% interval for the difference sits inside ± the smallest lift worth acting on. This is an equivalence test (two one-sided tests; Schuirmann 1987): absence of a difference is shown, not assumed.

Keep testing otherwise, with the visitors still needed to detect your smallest worthwhile lift at 80% power.

Traffic split check (sample ratio mismatch): a chi-square test of the visitor counts against your planned split; flagged at p < 0.001 (Kohavi, Tang & Xu, Trustworthy Online Controlled Experiments, 2020, ch. 21).

Always-valid p-value: the mixture sequential probability ratio test (Johari, Koomen, Pekelis & Walsh, "Always valid inference", Operations Research, 2022), with the mixing scale set to your smallest worthwhile lift. It stays valid however often you look. In this repository's simulation (5,000 tests where A and B are identical, checked up to 40 times) it raised a false alarm in under 2% of tests; a plain p-value did so in 29%.

always-valid p = min(1, 1/Λ), Λ = √(V/(V+τ²)) · exp( τ²·d² / (2V(V+τ²)) ) d = rate_B − rate_A, V = its variance, τ = smallest lift worth acting on (points)

Bayesian read: Beta-binomial posteriors for each rate (Gelman et al., Bayesian Data Analysis, 3rd ed.); expected loss is the average conversion rate you give up if you pick the version that is in fact worse.

What a longer test buys you

Smallest lift you can reliably detect (at your power and significance level) for each test length, at your traffic. Gains flatten quickly: halving the detectable lift takes four times the visitors.

How the plan is computed formula, sources

Visitors per version from the standard two-proportion formula (Fleiss, Levin & Paik, Statistical Methods for Rates and Proportions, 3rd ed., 2003). With more than two versions, each new version is compared with the original and the significance level is split across those comparisons (Bonferroni), so every comparison needs more visitors.

n per version = ( z₁₋α/₂ · √(2·p̄(1−p̄)) + z₁₋β · √(p₁(1−p₁) + p₂(1−p₂)) )² / (p₂ − p₁)²

Run length is rounded up to whole weeks, because weekday and weekend visitors often behave differently and a test that ends mid-week over-represents some days.

The plan assumes you read the result once, at the end. If you will check as you go, enter the number of checks in Analyze my test: it switches to the always-valid p-value, which stays honest under repeated looks but needs more data to call a winner.
